Use true or false for booleans, or leave blank for unknown. Dates accept ISO 8601 with offsets; dates without offsets use Mountain time. Compensation types: unknown, hourly, salary, fixed. Pay bases: unknown, employee_gross, contractor_gross, reported_net.

Import is atomic: an invalid row rejects the file without importing partial records. Matching entries are deduplicated; ambiguous matches stay separate. Imported records begin with New status. Include a stable source_id when importing updated snapshots from the same source. No fictional records are loaded by default.
